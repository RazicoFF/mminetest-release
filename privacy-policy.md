## Русский

**Разработчик:** razicoff. **Приложение:** MMineTest Подготовка (пакет: `uz.mminetest.tayyorgarlik`).

**Персональные данные.** Приложение не собирает, не хранит и не передаёт никаких персональных данных. Регистрация и создание учётной записи не требуются.

**Данные на устройстве.** История результатов и настройки хранятся только на вашем устройстве. Они не включаются в облачную резервную копию и не переносятся на другое устройство.

**Сетевой запрос.** Единственный сетевой запрос приложения — чтение публичного файла `version.json` на GitHub (raw.githubusercontent.com, razicoff/mminetest-release) по HTTPS для проверки обязательного обновления. Ваши данные в запросе не передаются. GitHub может записывать IP-адрес в свои стандартные серверные журналы. Приложение использует только разрешение INTERNET.

**Реклама и третьи стороны.** В приложении нет рекламы, аналитики и сторонних SDK.

**Дети.** Приложение не предназначено для детей.

**Контакты.** По вопросам: mexpugguh@gmail.com или https://github.com/razicoff/mminetest-release/issues

## English

**Developer:** razicoff. **App:** MMineTest Tayyorgarlik (package: `uz.mminetest.tayyorgarlik`).

**Personal data.** The app does not collect, store, or transmit any personal data. No registration or account is required.

**Data on your device.** Your results history and settings stay only on your device. They are excluded from cloud backup and are not transferred to another device.

**Network request.** The app's only network request is an HTTPS read of the public `version.json` file on GitHub (raw.githubusercontent.com, razicoff/mminetest-release) to check for a mandatory update. No data about you is sent in the request. GitHub may record your IP address in its standard server logs. The app uses only the INTERNET permission.

**Ads and third parties.** The app contains no ads, no analytics, and no third-party SDKs.

**Children.** The app is not intended for children.

**Contact.** For questions: mexpugguh@gmail.com or https://github.com/razicoff/mminetest-release/issues
